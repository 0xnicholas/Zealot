## Agent skills

### Issue tracker

Issues live as GitHub issues on this repo, operated via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage labels, default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` at the root with ADRs in `docs/adr/`. See `docs/agents/domain.md`.
